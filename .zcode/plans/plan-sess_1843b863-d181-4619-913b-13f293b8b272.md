# aria 项目 agent 配置迁移到 ZCode（软链优先，单一内容源）

## 映射总览

| Claude Code 现状 | ZCode 等价格式 | 迁移方式 |
|---|---|---|
| `CLAUDE.md`（常驻指令，150 行） | `<repo>/AGENTS.md`（工作区指令文件） | 相对软链 `AGENTS.md -> CLAUDE.md` |
| `.claude/rules/*.md`（9 个，`paths:` 自动加载） | `.zcode/skills/aria-*/SKILL.md`（description 自动触发） | frontmatter 补 `name`/`description` + 软链 |
| `.claude/reference/**`（8 个按需读设计文档） | 无需迁移 | 路径引用不变，ZCode 直接 Read |
| `.claude/settings.local.json`（Claude 专属 attribution） | 无对应 | 不迁移 |

关键依据：ZCode SKILL.md frontmatter 只认顶层平铺键，`name`/`description` 必填（缺失则技能被丢弃），未知键与缩进行被忽略——因此规则文件补上这两个键后可直接软链为 SKILL.md，`paths:` 对 ZCode 无害；Claude Code 侧同样忽略多余的 `name`/`description` 键，一份文件两边共用。

## 实施步骤

### 1. 给 9 个规则文件增强 frontmatter
对 `.claude/rules/{core,util,value,error,compile,bytecode,runtime,object,memory}.md`，在 `paths:` 之前插入：
- `name: aria-<n>`（与技能目录名一致）
- `description: <中文触发描述>`：前 250 字符内写明触发条件（如「读写 src/error/**、涉及错误通道/Result 返回/VM 异常设计时使用」），总长 < 1024 字符

保留 `paths:` 原样。注意 `error.md`/`memory.md`/`runtime.md` 当前有未提交修改，只动 frontmatter 不碰正文。

### 2. AGENTS.md 软链（根目录）
```
ln -s CLAUDE.md AGENTS.md
```
CLAUDE.md 保持为真实文件（项目内所有「见 CLAUDE.md」引用无需改动）。

### 3. 建 9 个 ZCode 技能（目录 + 软链）
```
mkdir -p .zcode/skills/aria-<n>
ln -s ../../../.claude/rules/<n>.md .zcode/skills/aria-<n>/SKILL.md
```
n ∈ {core, util, value, error, compile, bytecode, runtime, object, memory}，全部相对软链保证仓库可移植。

### 4. CLAUDE.md 三处小改（软链生效后改一份两边同步）
- L5 注记块：补充「`AGENTS.md` 为本文件的软链，作为 ZCode 工作区指令入口」
- 「文档与参考」节：三层组织说明补充 ZCode 侧入口（AGENTS.md 软链；rules 经 `.zcode/skills/aria-*/` 软链暴露为 ZCode 技能，按 description 自动触发）
- 「关键模块」节：表格后补一句规则文件与 ZCode 技能的对应关系

### 5. 验证
- `ls -l` 确认 10 个软链全部正确解析
- 逐个检查 9 个规则 frontmatter：`name`/`description` 为顶层平铺键、description < 1024 字符
- 提示：需重启 ZCode 会话，在 Settings → Skills 或 `/` 菜单确认 9 个 `aria-*` 技能出现（客户端发现无法从命令行直接验证）

## 明确不做
- `reference/` 不动：所有 `.claude/reference/...` 路径引用继续有效
- 不创建 `.zcode/config.json`（无 MCP/hooks/commands 需求）
- 不迁移 `settings.local.json`（attribution 为 Claude 专属，ZCode 有自己的客户端设置）
- 不做 git 提交：工作区已有未提交改动，新增文件（AGENTS.md、.zcode/）留给你审查后自行入库；`.zcode/` 未被 .gitignore 忽略，可直接 add

## 已知注意点
- Windows 检出该仓库需启用开发者模式或 `core.symlinks=true`，否则 git 会把软链物化成纯文本文件（AGENTS.md 内容会变成一行 "CLAUDE.md"）。macOS/Linux 无影响。
- 同名技能用户级会遮蔽工作区级，`aria-` 前缀已规避常见通用词冲突。
