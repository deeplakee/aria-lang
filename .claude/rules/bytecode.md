# bytecode 层模块参考

指令功能/操作数位宽/栈效应的完整规格见 `.claude/reference/bytecode/bytecode-instruction-set.md`（按需 Read）。

- `bytecode/code.hpp`：**指令集单一事实源 = `ARIA_OPCODE_LIST(X)` X-Macro 双列表**（每行 `X(枚举名, OpFormat类别)`，63 条；枚举顺序即 opcode 数值，首条 `HALT` 隐式为 0）。表展开生成 5 样：`OpCode` 枚举 / `OpFormat`（操作数格式类别，11 种：`Simple`/`U8`/`U16`/`ConstU16`/`ImmI8`/`JumpFwd`/`JumpBack`/`RangeFlags`/`RegU8`/`Import`/`Invoke`）/ `kOpCodeCount`（越界判定用，替代依赖枚举稠密）/ `kOpCodeNames` / `kOpCodeFormats`（`inline constexpr` 查表，供 Disassembler 等冷路径消费；VM 热路径不查表）。**新增指令流程：X 表加一行（选既有 OpFormat）→ AriaVM 加对应 case → 文档同步；Disassembler 与名字/格式表零改动**（仅引入新格式类别时才同步其分发 switch）。表内不放说明性注释（中英混排难以列对齐），语义细节统一放表头注释块速览与 `bytecode-instruction-set.md`；续行符 `\` 对齐交给 clang-format（`RightAlignEscapedNewlines`）自动维护，无需手工对齐；若确需表内注释只能用块注释 `/* */`（多行宏体内 `//` 会因反斜杠续行吞掉下一行）。未来 computed goto 跳转表是同表再加一行消费。指令清单含 `LOAD_CONST`/`LOAD_IMM`/`LOAD_NIL`/`LOAD_TRUE`/`LOAD_FALSE`/`LOAD_LOCAL`/`STORE_LOCAL`/`LOAD_LOCAL_L`/`STORE_LOCAL_L`（长变体，slot u16）/`LOAD_UPVALUE`/`STORE_UPVALUE`/`CLOSE_UPVALUE`/`DEF_GLOBAL`/`LOAD_GLOBAL`/`STORE_GLOBAL`/`LOAD_FIELD`/`STORE_FIELD`/`LOAD_INDEX`/`STORE_INDEX`/`LOAD_THIS_FIELD`/`STORE_THIS_FIELD`/算术与比较（含 `NOT_EQUAL`/`STRICT_EQUAL`/`STRICT_NOT_EQUAL`）/`NOT`/`NEGATE`/栈操作（`POP`/`POP_N`/`DUP`/`DUP2`）/`JUMP*`（含 `JUMP_TRUE_OR_POP`/`JUMP_FALSE_OR_POP` 短路）/`CALL`/`CLOSURE`/`LOAD_REG`/`MAKE_CLASS`/`MAKE_METHOD`/`MAKE_STATIC`/`LOAD_SUPER_FIELD`/`INVOKE_METHOD`(预留指令,编译器不发射、VM 命中 `not_implemented`)/`MAKE_LIST`/`MAKE_MAP`/`MAKE_RANGE`/`IMPORT`/`THROW`/`RETURN`/`HALT`/`PRINT`/`NOP` 等；**无 `SETUP_EXCEPT`/`END_EXCEPT`**--异常走 CodeUnit 内记录表，见 `CLAUDE.md`「错误处理」第 2 条。
- `bytecode/CodeUnit.hpp`：`CodeUnit` 字节码容器（`ObjFunction` 的值成员，非 Object）。头内置**操作数位宽事实源** `kU8OperandMax`/`kU16OperandMax`（u8/u16 操作数最大 255/65535，`namespace aria` 级 constexpr），本类与 CodeGen 的各语义上限常量（本侧 `kMaxPopChunk`/`kMaxShortLocalSlot`/`kMaxJumpOffset`/`kMaxConstantCount`、CodeGen 侧 `kMaxArity`/`kMaxArguments`/`kMaxConstants`/`kMaxLocals`）以之为源。`explicit CodeUnit(GC* gc)`（容器分配器绑定 GC）。四个容器字段直接 public 裸露：`code`（`Array<u8>` 字节流，opcode + 内联操作数小端）、`constants`（`AriaArray` 常量池，白赚 `trace`）、`lines`（`Array<LineEntry>` RLE 行段表，`LineEntry{offset,line}`）、`try_records`（`Array<TryRecord>` 异常记录表，`TryRecord{begin,end,handle,stack_depth}` 按 `begin` 非降序（CodeGen 入口预插占位 + 结尾回填保证；相等合法--内层 try 是外层体首条语句时零发射间隔，二分前溯的反向扫描天然取最内层）；`handle` 为 catch handler 入口 offset，`stack_depth` 为 try 入口局部数编译期快照，unwind 据此截值栈并把异常值落 catch 参数槽）；VM/编译器/反汇编器直接操作裸字段。仅保留有不可散落逻辑的方法：`emit_byte`/`emit_word`/`emit_op`（带 `line`，RLE 行号记录收口于私有 `record_line_`）、`emit_pop_n`（分块 emit POP_N，每块<=255）、`emit_jump(op,line)->usize`（发 op + 占位 u16，返回占位偏移 src_off）、`patch_jump(src_off)->bool`（前向回填 `target_off - base_off`，base_off = 读完 u16 操作数后的 ip；越界>65535 返 false 不写）、`emit_jump_back(target_off,line)->bool`（后向 JUMP_BACK + `base_off - target_off`；越界 emit 占位 word 0 后返 false）、`emit_load_local`/`emit_store_local(slot,line)`（slot<=255 短变体 +u8 / 否则长变体 _L +u16）、`size()->u32`（= `code.size()`，下一条 emit 的 offset）、`add_constant`（越界断言 + 返回 `u16` 索引）、`line_for_offset`（RLE 二分查行）、`find_try_handler`（按 `ip` 二分查最近覆盖的 try 记录，返 `Opt<const TryRecord*>` 指向命中记录，unwind 读其 `handle`/`stack_depth`）、`trace`（委托 `constants.trace`）、`disassemble(name)`（委托 `Disassembler::disassembleCodeUnit`）。**字节码编码逻辑（emit/跳转编码/回填/分块/槽位变体）收口于此**（编译器不再自持薄包装）；越界以 bool 返回交调用方翻译为 Error，本类不持 Error 语义。行号无状态模型：emit 一律带 `line`（无重载、无 `last_line_`，调用方自跟踪当前行）。非拷贝/非移动。
- `bytecode/Disassembler.hpp`/`.cpp`：字节码反汇编器，把 `CodeUnit` 字节流解码为可读文本（供调试/调试器/测试核对）。`explicit Disassembler(const CodeUnit*, StringView name)`（name 须在 `disassemble()` 期间存活）；实例持解码游标（`codeunit_` + `offset_`），`disassemble()` 从头解码整个 `CodeUnit`（每次调用复位游标，对象可复用）；静态便捷入口 `disassembleCodeUnit(codeunit, name)`。底层读取 `read_u8()`/`read_u16()`（推进 `offset_`）+ 常量注释渲染（只读不推进）；逐指令解码由 `.cpp` 内联解码表驱动。静态单指令入口 `disassembleInstruction(codeunit, offset)->String`（构造一次性 Disassembler、拨 `offset_` 到 offset、调私有 `dis_instruction()` 返回该指令文本，与 `disassemble()` 每行指令段一致；仅推进局部游标不修改入参 offset；供 VM 执行跟踪 `DEBUG_TRACE_EXECUTION` 在每条指令执行前打印其反汇编，免为跟踪复制解码表）。输出含表头 `== name ==` + `constants:` 小节（非空才列）+ `try records:` 小节（非空才列，M3 异常记录表逐条：`索引: [begin, end) handle=... stack_depth=...`）+ `code:` 小节（逐指令，每行：偏移 4 hex | 行号 | opcode 名 | 操作数 hex | ; 解析注释（常量值/名字/跳转目标/立即数））+ 结尾 `== end ==`。**解码表驱动**：`dis_instruction()` 越界判定用 `byte >= kOpCodeCount`，名字/格式查 code.hpp X 表生成物（`kOpCodeNames`/`kOpCodeFormats`），按 11 种 `OpFormat` 分发到解码函数（`simple_instruction`/`u8_instruction`/`u16_instruction`/`const_instruction`/`load_imm`/`jump_forward`/`jump_back`/`make_range`/`register_instruction`/`import_instruction`/`invoke_instruction`）；名字索引指令与 `LOAD_CONST` 同走 `ConstU16` 格式（无独立 `name_instruction`）。渲染回归由 `tests/bytecode/test_disassembler.cpp` 锁定（每格式一条）。
