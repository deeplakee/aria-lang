# object 层模块参考

- `object/Object.hpp`：`Object` 基类（`next_` 链/`hash_`/`type_`/`is_marked_`）+ `ObjType`（BASE/STRING/FUNCTION/NATIVE_FN/UPVALUE/CLASS/INSTANCE/BOUND_METHOD/LIST/MAP/MODULE/RANGE/ITERATOR/EXCEPTION）；虚 `trace(GC&)`/`size()`/`equals(const Object*)`（== 内容相等，默认 `this==other`，子类型按内容 override）/`to_string()`（基类默认 `<Type at 0xaddr>`，子类型 override）/`~Object`；公共访问器 `hash()`/`type()`/`is_marked()`/`mark()`/`unmark()`（GC 标记用）。地址哈希经 `util::hash_addr` + 两 ctor（内容哈希 `Object(u32,ObjType)` / 地址哈希 `Object(ObjType)`）。`as<T>`/`is<T>` 模板仅 `Object*`/`const Object*` 重载（DEBUG `dynamic_cast`，否则 `static_cast`；`is<T>` 目前一律 `dynamic_cast`，子类型落地后改 `ObjType` 查表，见代码 TODO）。`Object.hpp` 不 include `value/Value.hpp`：`Object` 自前向声明供 `DerivedFromObj` concept 用，Value↔Object 的实现依赖置于 `Value.cpp` 一侧。自由函数 `log_obj_alloc(Object*)`（DEBUG 日志：打印地址/size/类型名）。子类型已落地 `ObjString`/`ObjFunction`/`ObjNativeFn`/`ObjModule`。
- `object/ObjString.hpp`/`.cpp`：SSO 字符串（`kShortCapacity=15`，短串内联 / 长串 `long_chars_` 独立 buffer；`is_long()` 由 `length_ > kShortCapacity` 派生不存标志位），FNV-1a 哈希（经 `util::hash_str`）。访问器 `view()`/`length()`；`equals(const Object*)` override（先比指针 intern 命中快速路径、再比 `view()` 字符内容）；`to_string()` override 返字符内容原文（无引号，如 `hello`）。`new_string` 工厂（Phase 2 起经 GC `InternPool` 驻留：等价内容共享同一 `ObjString*`，命中不分配不 GC，未命中 `new_object` + `intern_insert`）。`new_string` 内部对 `intern_insert` 窗口**不加守卫**：`s` 虽此刻白色无根，但 `intern_insert -> InternPool::insert -> allocate<ObjString*>` 走 trivial 分配（永不触发 GC，见 `GC.hpp` 核心不变式），故 `s` 跨 insert 不会被回收。`name`/`module` 跨 `new_object` 顶部 `maybe_collect` 的守卫仍保留（那是真 GC 触发点，承重）。。
- `object/ObjFunction.hpp`/`.cpp`：函数对象（`ObjFunction final : Object`，`ObjType::FUNCTION`）：持 `CodeUnit unit_` 值成员（编译器经 `unit()` 直接操作裸字段 emit）+ `ObjModule* module_`（所属模块，词法归属，构造时传入、不可变、非空；VM 据此定位「当前模块 globals」）+ `ObjString* name_`（intern 同指针；**恒非空**，ctor ASSERT 非空--入口函数名 `<main>`（主入口）/`<module>`（导入）、lambda 名 `<anonymous>`、具名函数为声明名；`<>` 是正常标识符中不可用的符号，具独特辨识度；统一「每个函数都有名字」模型）+ `u8 arity_`（参数个数，上限 255）。访问器 `unit()`（非 const + const 重载）/`name()`/`arity()`/`module()`。地址哈希型；`equals` 保持默认地址相等（函数无内容相等语义）；`trace()` 标 name_ + module_ + 委托 `unit_.trace`（常量池；module_ 回指形成 module<->entry 环，mark-sweep 三色标记天然破环）；`to_string()` 统一渲染 `<fn name>`（入口 `<fn <main>>`/`<fn <module>>`、lambda `<fn <anonymous>>`、具名 `<fn add>`）；工厂 `new_function(gc, module, name, arity)` **不替调用方守卫入参**（「每方只守自己创建的」），只做一次 `new_object`、无内部新建对象；调用方须在调用前自行根化 module 与 name（皆不保命：module 可能尚未入 VM 模块表、name 经 intern 是 weak root），跨 `new_object` 顶 maybe_collect。
- `object/ObjNativeFn.hpp`/`.cpp`：原生函数对象（`ObjNativeFn final : Object`，`ObjType::NATIVE_FN`），把 C++ 函数包成 aria `Value`，供 builtins 与嵌入 API 用。签名 `using NativeFn = bool (*)(AriaVM& vm, Span<Value> slots)`：`slots[0]`=槽 0（callee/返回槽，原生函数把返回值写于此）、`slots[1..argc]`=实参（`argc=slots.size()-1`，天然变参、不存 arity，fn 自查元数）；返回 `bool`（true=成功写槽 0、false=失败），`vm.fail`/`vm.raise` 置 `Movement` 挂起错误寄存器并返回 `false`，故失败路径惯用一行 `return vm.fail(...)`。`CALL` 命中时不进帧同步直接调用，VM 以 bool 为成败信号、寄存器为错误载荷（debug 断言 `ok == !has_error()`）。详见 `.claude/reference/runtime/vm-design.md` §4.7。持 `ObjString* name_`（可 nullptr 渲染 `<fn>`）+ `NativeFn fn_`（恒非空）；访问器 `name()`/`fn()`；地址哈希型；`trace` 标 name_；工厂 `new_native_fn(gc, name, fn)` **不替调用方守卫入参**，只做一次 `new_object`；调用方须在调用前自行根化 name（intern weak root），fn 为标量无需入根。
- `object/ObjModule.hpp`/`.cpp`：模块对象（`ObjModule final : Object`，`ObjType::MODULE`，非拷贝/非移动），aria 的「模块 = 命名空间」（非类），一个源文件 = 一个模块。持 `ObjString* name_`（相对源根的路径，intern，显示名 + 合成绝对路径用）+ `ObjString* root_`（所属源根目录，intern，指针恒非空、内容可空：cwd 不可用时 `new_module` 以空串兜底）+ `ObjFunction* entry_`（模块体，顶层语句编进的 arity 0 匿名函数，主入口名 `<main>` / 导入名 `<module>`，导入时 run-once；可为 nullptr）+ `AriaHashTable globals_`（模块级绑定表，顶层 var/fun/def 的目标，`LOAD/STORE/DEF_GLOBAL` 操作此表；惰性分配）+ `ModuleState state_`。`enum class ModuleState : u8 { Loading, Loaded }`（构造置 `Loading`；循环导入命中 `Loading` 返回半初始化对象）；访问器 `name()`/`root()`/`globals()`（非 const + const）/`entry()`/`set_entry(ObjFunction*)`/`state()`/`set_state(ModuleState)`。`abs_path()` 合成绝对文件路径（= VM 模块表查重键形式）：`root_` 内容空 -> 返空串（无源根锚点）；`name_` 为 nullptr 或空串 -> 仅返 `root_`；否则 `root_ + "/" + name_ + ".aria"`（供 IMPORT 相对导入取 dirname 作基）。地址哈希型；`equals` 保持默认地址相等（模块按身份判等）；`trace()` 标 name_ + root_ + entry_ + 委托 `globals_.trace`；`to_string()` 渲染 `<module name>`（name_ nullptr 渲染 `<module>`）。工厂 `new_module(gc, name, root)`（显式源根，root 指针须非空）/ `new_module(gc, name)`（无显式源根取 cwd，不可用空串兜底）/ `new_module(gc, StringView name)`（name 以 StringView 传入，工厂内部 `new_string` 驻留并自行守卫，调用方无需手动建串根化）/ `new_module(gc, StringView name, StringView root)`（name 与 root 均以 StringView 传入，工厂内部 `new_string` 驻留 name/root 串并自行守卫，调用方无需根化任何入参；root 原样 intern 调用方给的串，空串即空串锚点，**不替调用方做 cwd 退化**--需退化用 2 参 StringView 重载）**不替调用方守卫入参**：3 参 `ObjString*` 版只做一次 `new_object`，调用方须自行根化 name 与 root；`ObjString*` 2 参版内部新建 root_str（cwd 串）故自行守卫 root_str（工厂守「自己创建的」），但 name 仍须调用方根化；`StringView` 两版内部新建的 name_str/root_str 均自行守卫，调用方无需根化任何入参。置 `Loading` 态。
