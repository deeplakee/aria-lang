# bytecode 层模块参考

指令功能/操作数位宽/栈效应的完整规格见 `.claude/reference/bytecode/bytecode-instruction-set.md`（按需 Read）。

- `bytecode/code.hpp`：`OpCode` 枚举（`LOAD_CONST`/`LOAD_IMM`/`LOAD_NIL`/`LOAD_TRUE`/`LOAD_FALSE`/`LOAD_LOCAL`/`STORE_LOCAL`/`LOAD_LOCAL_L`/`STORE_LOCAL_L`（长变体，slot u16）/`LOAD_UPVALUE`/`STORE_UPVALUE`/`CLOSE_UPVALUE`/`DEF_GLOBAL`/`LOAD_GLOBAL`/`STORE_GLOBAL`/`LOAD_FIELD`/`STORE_FIELD`/`LOAD_INDEX`/`STORE_INDEX`/`LOAD_THIS_FIELD`/`STORE_THIS_FIELD`/算术与比较（含 `NOT_EQUAL`/`STRICT_EQUAL`/`STRICT_NOT_EQUAL`）/`NOT`/`NEGATE`/栈操作（`POP`/`POP_N`/`DUP`/`DUP2`）/`JUMP*`（含 `JUMP_TRUE_OR_POP`/`JUMP_FALSE_OR_POP` 短路）/`CALL`/`CLOSURE`/`LOAD_OBJECT`/`MAKE_CLASS`/`MAKE_METHOD`/`MAKE_STATIC`/`LOAD_SUPER_METHOD`/`INVOKE_METHOD`(预备,暂 pass)/`MAKE_LIST`/`MAKE_MAP`/`MAKE_RANGE`/`IMPORT`/`THROW`/`RETURN`/`HALT`/`PRINT`/`NOP` 等；**无 `SETUP_EXCEPT`/`END_EXCEPT`**--异常走 CodeUnit 内记录表，见 `CLAUDE.md`「错误处理」第 2 条。
- `bytecode/CodeUnit.hpp`：`CodeUnit` 字节码容器（`ObjFunction` 的值成员，非 Object）。`explicit CodeUnit(GC* gc)`（容器分配器绑定 GC）。四个容器字段直接 public 裸露：`code`（`Array<u8>` 字节流，opcode + 内联操作数小端）、`constants`（`AriaArray` 常量池，白赚 `trace`）、`lines`（`Array<LineEntry>` RLE 行段表，`LineEntry{offset,line}`）、`try_records`（`Array<TryRecord>` 异常记录表，`TryRecord{begin,end,handle}` 按 `begin` 单调；`handle` 为 catch handler 入口 offset）；VM/编译器/反汇编器直接操作裸字段。仅保留有不可散落逻辑的方法：`emit_byte`/`emit_word`/`emit_op`（带 `line`，RLE 行号记录收口于私有 `record_line_`）、`emit_pop_n`（分块 emit POP_N，每块<=255）、`emit_jump(op,line)->usize`（发 op + 占位 u16，返回占位偏移 src_off）、`patch_jump(src_off)->bool`（前向回填 `target_off - base_off`，base_off = 读完 u16 操作数后的 ip；越界>65535 返 false 不写）、`emit_jump_back(target_off,line)->bool`（后向 JUMP_BACK + `base_off - target_off`；越界 emit 占位 word 0 后返 false）、`emit_load_local`/`emit_store_local(slot,line)`（slot<=255 短变体 +u8 / 否则长变体 _L +u16）、`size()->u32`（= `code.size()`，下一条 emit 的 offset）、`add_constant`（越界断言 + 返回 `u16` 索引）、`line_for_offset`（RLE 二分查行）、`find_try_handler`（按 `ip` 二分查最近覆盖的 try 记录，返 `Opt<u32>` handler offset）、`trace`（委托 `constants.trace`）、`disassemble(name)`（委托 `Disassembler::disassembleCodeUnit`）。**字节码编码逻辑（emit/跳转编码/回填/分块/槽位变体）收口于此**（编译器不再自持薄包装）；越界以 bool 返回交调用方翻译为 Error，本类不持 Error 语义。行号无状态模型：emit 一律带 `line`（无重载、无 `last_line_`，调用方自跟踪当前行）。非拷贝/非移动。
- `bytecode/Disassembler.hpp`/`.cpp`：字节码反汇编器，把 `CodeUnit` 字节流解码为可读文本（供调试/调试器/测试核对）。`explicit Disassembler(const CodeUnit*, StringView name)`（name 须在 `disassemble()` 期间存活）；实例持解码游标（`codeunit_` + `offset_`），`disassemble()` 从头解码整个 `CodeUnit`（每次调用复位游标，对象可复用）；静态便捷入口 `disassembleCodeUnit(codeunit, name)`。底层读取 `read_u8()`/`read_u16()`（推进 `offset_`）+ 常量注释渲染（只读不推进）；逐指令解码由 `.cpp` 内联解码表驱动。静态单指令入口 `disassembleInstruction(codeunit, offset)->String`（构造一次性 Disassembler、拨 `offset_` 到 offset、调私有 `dis_instruction()` 返回该指令文本，与 `disassemble()` 每行指令段一致；仅推进局部游标不修改入参 offset；供 VM 执行跟踪 `DEBUG_TRACE_EXECUTION` 在每条指令执行前打印其反汇编，免为跟踪复制解码表）。输出含表头 `== name ==` + `constants:` 小节（非空才列）+ `code:` 小节（逐指令，每行：偏移 4 hex | 行号 | opcode 名 | 操作数 hex | ; 解析注释（常量值/名字/跳转目标/立即数））+ 结尾 `== end ==`。与 VM 共用「opcode -> 操作数格式」解码约定（`bytecode-instruction-set.md` §2.1/§8），解码表当前内联于 `.cpp`。
